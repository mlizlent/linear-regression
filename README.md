# Linear Regression Exercises

A collection of Jupyter notebooks demonstrating linear regression concepts and implementations.

## Project Structure

```
linear-regression/
├── ex00/          # Exercise 00 - Setup and basics
├── ex01/          # Exercise 01 - Simple linear regression
├── ex02/          # Exercise 02 - Multiple linear regression
├── ex03/          # Exercise 03 - Polynomial regression
├── ex04/          # Exercise 04 - Regularization (Ridge, Lasso)
├── ex05/          # Exercise 05 - Model evaluation and validation
└── requirements.txt
```

## Exercises

| Exercise | Notebook | Description |
|----------|----------|-------------|
| ex00 | `Notebook_ex00.ipynb` | Environment setup and data exploration |
| ex01 | `Notebook_ex01.ipynb` | Simple linear regression |
| ex02 | `Notebook_ex02.ipynb` | Multiple linear regression |
| ex03 | `Notebook_ex03.ipynb` | Polynomial regression |
| ex04 | `Notebook_ex04.ipynb` | Regularization techniques (Ridge, Lasso) |
| ex05 | `Notebook_ex05.ipynb` | Model evaluation and cross-validation |

## Requirements

- Python 3.10+
- numpy
- pandas
- matplotlib
- scikit-learn
- ipykernel

Install dependencies:
```bash
pip install -r ex00/requirements.txt
```

## Usage

Open any notebook with Jupyter:
```bash
jupyter notebook ex00/Notebook_ex00.ipynb
```

Or use JupyterLab:
```bash
jupyter lab
```
